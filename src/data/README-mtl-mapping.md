# MTL→RAL-Mapping

Die kanonische Datei liegt unter **`public/mtl-ral-color-mapping.json`** (nicht mehr unter `src/data/`).

Erzeugen: MTL-Colormatching-Tool oder `npm run mtl:slim-mapping` (liest standardmäßig `public/mtl-ral-color-mapping.json`).

Produkt-Stammdaten aus MTL synchronisieren: `npm run sync:colors`.
